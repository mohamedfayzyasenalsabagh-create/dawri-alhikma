# دوري الحكمة

موقع وتطبيق أندرويد لدوري كرة القدم في ثانوية دار الحكمة.

- صفحة الجمهور: https://dawri-alhikma.web.app
- لوحة الإدارة: https://dawri-alhikma.web.app/admin
- التطبيق: https://mohamedfayzyasenalsabagh-create.github.io/dawri-alhikma/dawri-alhikma.apk

البيانات محفوظة في Firestore (المستند `league/state`)، والتعديل مسموح لحساب المشرف فقط حسب `firestore.rules`.
كل دفع على `main` بيبني التطبيق وبينشر الموقع تلقائياً.
